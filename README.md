# distance-conversion
Convert Kilometers to Miles

## conversion options
I have provided two versions in the app.js file.
The first will not round to 2 decimal points. The second will. You will need to
comment out the version that you do not want to use. The second version is active
by default.

### how to convert
Simply enter the number of miles either by typing it in the form provided or selecting it from the up/down arrows to the right of the number field.
